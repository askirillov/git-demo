# git-demo

## Hidden File Finder — приложение для поиска спрятанных файлов

В репозитории есть готовый Python-скрипт `file_search_gui.py`, который запускает цветное графическое приложение для поиска обычных и скрытых файлов на компьютере.

### Как запустить из исходников

```bash
python3 file_search_gui.py
```

На Windows можно использовать:

```powershell
python file_search_gui.py
```

### Как собрать EXE и установщик для Windows

Сборку нужно запускать на Windows, потому что установщик создаётся Windows-инструментами.

1. Установите Python 3 для Windows и включите опцию **Add python.exe to PATH**.
2. Для создания установщика установите Inno Setup 6: <https://jrsoftware.org/isdl.php>.
3. Запустите в корне проекта:

```bat
build_windows.bat
```

После сборки появятся файлы:

- `dist\HiddenFileFinder.exe` — portable EXE, который можно запускать без установки;
- `dist\release\HiddenFileFinder-1.0.0-Windows-Portable.zip` — ZIP-релиз с готовым EXE и README;
- `dist\installer\HiddenFileFinderSetup.exe` — установщик Windows, если установлен Inno Setup.

Скрипт сборки использует `PyInstaller` из `requirements-build.txt`, файл `hidden_file_finder.spec` и `create_release_zip.py` для упаковки portable ZIP. Установщик описан в `installer/hidden_file_finder.iss`.

### Что умеет приложение

- искать обычные и скрытые файлы в выбранной папке;
- включать режим «только скрытые», чтобы быстро находить спрятанные файлы и скрытые папки;
- искать по нескольким маскам имени, например `*;*.log;secret*`;
- фильтровать результаты по расширениям, например `txt;log;db;zip`;
- использовать быстрые пресеты для скрытых файлов, документов, архивов, баз и логов;
- искать текст внутри небольших файлов до 5 МБ;
- ограничивать поиск минимальным и максимальным размером файла, например `10KB`, `2 MB`, `1.5GB`;
- видеть общее количество найденных файлов и отдельно количество скрытых;
- сортировать результаты по имени, типу, признаку скрытого файла, размеру и дате изменения;
- выделять один или несколько результатов;
- открывать файл двойным кликом;
- открывать папку выбранного результата;
- копировать пути выбранных файлов в буфер обмена;
- экспортировать найденные результаты в CSV;
- удалять выбранные файлы после подтверждения;
- останавливать долгий поиск.

Само приложение использует только стандартную библиотеку Python. Для сборки Windows EXE нужен только `PyInstaller`, а для полноценного установщика — Inno Setup.
